A local, read-only D2L archive.

D2L Archive is a Chrome extension for Kennesaw State University that saves the D2L pages you can already see into a searchable archive on your own computer. It shows what is due, what changed, and what was graded without changing anything in D2L.

Download the latest release Read the privacy policy

Read-only by design

No assignment submits, discussion posts, quiz attempts, or settings changes. Actions open the item in D2L.

Local only

No account, server, analytics, or third-party network requests. Archives live in your Downloads folder.

Built for KSU

The extension requests access only to kennesaw.view.usg.edu/d2l/*.

What it does

  • Archives courses, assignments, quizzes, grades, discussions, announcements, content, and files.
  • Shows upcoming work, recent updates, and grade summaries in a dashboard.
  • Exports JSON, CSV, Markdown, and page snapshots for offline review.
  • Downloads course files only when you turn that option on.

Install

Download the latest release ZIP, unzip it, then load the folder from chrome://extensions with Developer mode enabled. Full setup notes are in the repository README.
